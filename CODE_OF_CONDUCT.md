# Código de Conduta

Este projeto adota, de forma resumida, o espírito do [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Nosso compromisso

Queremos um espaço respeitoso e acolhedor para quem participa, seja qual for a experiência, idade, origem, identidade ou aparência.

## O que esperamos

- Tratar as pessoas com respeito e educação, inclusive quando discordar.
- Dar e receber críticas sobre o trabalho, não sobre a pessoa.
- Ter paciência com quem está começando.

## O que não é aceito

- Ofensas, assédio, discriminação, ameaças e insultos.
- Divulgar dados pessoais de outras pessoas (por exemplo, dados de anunciantes ou de vendedores) sem permissão.
- Spam e propaganda sem relação com o projeto.

## Aplicação

Os mantenedores (Code It Labs) podem editar, ocultar ou apagar comentários, issues e pull requests que fujam deste código, e bloquear quem insistir.

Para denunciar um comportamento, use os recursos do próprio GitHub: **Report content** no comentário ou na issue, ou **Block or report** no perfil da pessoa. Se o problema for com um mantenedor, a denúncia ao GitHub também vale.
